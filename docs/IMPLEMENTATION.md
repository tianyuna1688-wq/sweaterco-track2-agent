## 技术决定

React + TypeScript + Vite 前端；FastAPI/Pydantic 后端；CSV 只读事实源；SQLite 保存建议和当前会话。显式有界状态机替代非必需 LangGraph 依赖，每次请求可审计。模型仅用于结构化语言理解，业务计算与官方 allocator 完全不调用模型。默认单用户本机使用，模型密钥仅注入服务端。

聊天参考日固定 2026-04-01；现实系统时钟仅用于审计时间戳。默认不启用工序扩展，可在界面独立选择。官方模拟器为 7 天/周自然日，不套用 Primer 中厂内 6 天工作制。运输不占生产队列。官方 `round` 日期与聊天风险日期分开展示并注明。

完整 Python 后端与官方 harness 需要 Python 运行时，交付为本地全栈项目和容器，而非把模拟器改写为静态网页以适配托管。
